### The professional toolkit
- **Resume bullet formula:** Action + Skill + Tool + Result.
  - Weak: "Used SIEM tool for monitoring."
  - Strong: "Investigated phishing alerts using SIEM and created IOC-based incident reports."
- **2-3 strong projects** are enough, with 2-3 bullets each.
- **One page:** Name and contact -> Skills -> Projects -> Certifications -> Education. No graphics, tables or photos (ATS-friendly).
- **LinkedIn:** keep it current, and post completed labs and certificates.
- **Daily practice:** 30-60 minutes on TryHackMe / Hack The Box, with a short notes file of what I learned.
- **CTFs:** beginner-friendly events, focusing on method rather than rank.
- **Networking rule:** connect -> thank -> stay in touch. Build the relationship before asking for a job.
- **HR prep:** "Tell me about yourself", "Why cybersecurity?", "What does your day look like?", strengths and weaknesses.
- **Applying:** 5-10 applications a day, tracked in a sheet, with a follow-up after 7 days. Rejection is normal.

### Portfolio website
The course provides a structured prompt for generating a simple static portfolio: plain HTML/CSS/JavaScript, no framework, sections for About, Skills, Projects (with detail pop-ups), Certifications, Resume and Contact, deployable by drag-and-drop on Netlify or on GitHub Pages.
